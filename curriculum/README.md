# Kaynak sözleşmesi

`grade-2.json` içindeki öğrenme çıktıları kısa, özgün Türkçe özetlerdir; resmî programın birebir metni değildir. Kod ve kaynak bağlantısı asıl MEB metnine götürür. Ders içerikleri özgün olarak hazırlanır. Akademik yıl 2026–2027; sınıf düzeyi 2.

Güncelleme komutu ağdan kaynak kontrolü yapar, HTTP hatalarını doğrulama saymaz, SHA-256 ile değişiklik raporu oluşturur. Onaylı veriyi otomatik değiştirmez. `reviews/` gözden geçirildikten sonra editör JSON'u günceller. Bir çıktının varlığı, uygulamanın o çıktının tüm süreç bileşenlerini ölçebildiği anlamına gelmez; gözlem gerektirenler ayrı işaretlenir.
